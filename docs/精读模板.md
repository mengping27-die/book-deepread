# 📖 书籍精读模板

> **用途**：精读任何一本书前，先看此文件选档（标准版/简版），按对应模板结构写。
> **选择规则**：见下方"选档规则"。写完后：登记索引 + 同步备份。

---

## 选档规则

| 档位 | 适用 | 示例 |
|:--|:--|:--|
| **标准版** | 公认经典 / 与使用者处境强相关 / 需深入理解 | 《菜根谭》《思考，快与慢》《系统之美》 |
| **简版** | 一般书籍 / 快速了解 / 次要参考 | 杂学书、方法论小册子 |

判断标准：这本书是否值得反复咀嚼？是否会影响你的决策/认知？是 → 标准版。

> **怎么读** → 见《精读指令》**第零条「怎么读」**（先读目录搭骨架、每章合上书用一句话说清、盯章首引语与章末小结、区分主张与依据、标出「但是/然而」处）。那五条比格式重要。

## 一、标准版（深度精读）

### 文件头

> **本块是 frontmatter 的格式真源** —— 要复制就复制这里。
> 各字段的**含义**（source / source_note / confidence / source_type 各答什么）见《精读指令》第一条，此处不重复。

```markdown
---
title: 《书名》精读
created: YYYY-MM-DD
tags: [标签1, 标签2]
source: 书名·作者·出版社·版本·章节数或页数·文件形式（PDF/epub）
source_type: （入库时由库方填；精读阶段留空。取值只能是既定枚举，不许自造）
source_note: 实际读法——全文还是节选、有无 OCR、抽样了哪几章、过程里遇到的问题
confidence: 高 / 中 / 低
---

# 书名 — 精读

## 全书核心
（1-2 段总括全书主旨 + 全书金句 1-2 条）

## 全书骨架
（**读之前先填这张表**：它逼你先把体系搭出来，填不出来的章就是接下来要重点读的）
（**读完之后再回来核对**：哪几行填错了？那正是你原先理解偏的地方）

| 章 | 一句话核心 |
|:--|:--|
| 1 | |
| 2 | |
| … | |
```

> **创作背景**（可选，放在「全书核心」之前）：**古籍、老书必补** —— 脱离时代读会误判。
> 例：一本 1993 年的系统科学著作，书中的人口 / 能源例子带有时效性。
> **只写书里有的**（序言、版权页、作者自述）；查不到就写「本书未交代创作背景」，**不许从外部补**。

### 正文结构
```markdown
## 上篇/下篇（或按原书篇章）

### 第X章 章名（详）

> **本章一句话**：（读完全章后合上书写的。写不出来 = 这章没读进去，回去重读）
> **论证路径**：主张（本章要立什么）→ 依据（用什么立的）→ 结论（最后落到哪）
> **在全书的位置**：承接前面什么、为后面铺什么

**章首引语**（若原书有）：> 「原文」，署作者（章节开头常有名家引言，那是作者选来点题的话）
**本章小结**（若原书有）：> 「原文」（作者自己的章末总结，往往是**最权威的章节核心**）

（两行都是作者原话、都要能定位；**原书没有哪一行，就整行省略**）

#### 小节名
**核心观点**：**1–3 句**说清这一节在立什么。（**宁可写长一点，也别写成一句空话**——
一句空话会被下面的「延伸」抢戏，最后两栏都在说同一件事）
**依据**：作者凭什么这么说——举了什么例子/数据/推理（**只记书上有的**）
**延伸**（**只放三类：机制或因果链 · 边界条件或前提 · 可操作的动作。放不进去的别写**）：
- …

**本章金句**（章末统一收口；**只收承载观点的**，如「一直保持恒定的系统恰恰是不具备适应力的」，不收纯修辞的）：
> 「原文引用」（章节定位）

---

### 第X章 章名（略）

> **本章一句话**：…
> **为什么略**：铺垫章 / 案例与前面重复 / 纯背景交代 …

**留意**（可选，一两条；没有就整节只有上面两行）
- 这一章里唯一值得单独记的东西
```

### 枚举型章节（清单 / 分类章）怎么写

有些章不是「论证推进」，而是**并列的清单**——如一本逻辑书的「28 种谬误」、一本说服力著作的「六大原则」、医书的方剂目录。

**这类章不要硬套「小节 + 核心观点/依据/延伸」**：几十条各写三栏，又臃肿又难查。**改用表格**：

```markdown
### 第X章 章名（详）

> **本章一句话**：这一组东西是干什么用的
> **在全书的位置**：…

| # | 名称 | 一句话要害 |
|:--|:--|:--|
| 01 | … | … |

**其中最关键的两三条**（表后单独展开成小节）：
#### 最要命的那一条
**核心观点** / **依据** / **延伸**
```

**三条规矩**：
1. **每行必须"一句话就能用"** —— 读者扫一眼能拿走，不是把原文缩写成摘要
2. **表前先给总纲** —— 这一组东西解决什么问题
3. **别平均用力** —— 表里平铺，但最要命的 2–3 条要在表后单独展开

### 「详」与「略」怎么定

标准版**不必每章等重**。详读章要覆盖三类：**全书地基 · 核心方法 · 行动指南**
（与《精读指令》附录 A 的第六查是同一个判据——**详读的是骨头，不是好啃的肉**）。

| 档 | 用在哪 | 写什么 |
|:--|:--|:--|
| **详** | 上面三类章 | 全套结构（骨架三行 + 章首引语/本章小结 + 各小节 + 本章金句） |
| **略** | 铺垫章 · 案例与别处重复的章 · 纯背景章 | 只写「本章一句话 + 为什么略」；需要时加一两条「留意」 |

> ⚠️ **两道闸**
> ① **若全书一章都定不出「详」** —— 这本书本就不该用标准版，改用简版。
> ② **「略」的理由必须写出来**（写在「为什么略」里），**不能只写一个「略」字**。
> 空白的理由就是偷工；并且**覆盖度报告里的详/略分布必须与正文一致**，对不上就是自打嘴巴。

### 标签与「原文／概述」的关系（重要）

模板里的 **本章一句话 / 论证路径 / 在全书的位置 / 核心观点 / 依据 / 延伸** ——
**这些标签下的内容，性质上就是"我的话"，等同于《精读指令》要求的【概述】。**
不必再逐句加【概述】前缀——**标签本身已经是标记**。

反过来，只有三处是**作者原话**，必须能定位：
- **章首引语**（章节开头的名家引言）
- **本章小结**（作者自己的章末总结）
- **本章金句**（`> 「…」`）

于是两条规则统一成一句话：

> **看它在不在标签下 —— 在，就是我的话；看它在不在引号里 —— 在，就是作者的话。**

### 论证路径填不出来时

`论证路径` 假设原书是**线性论证**（主张→依据→结论）。这对教材、论著、科普都成立，但**格言体、笔记体、散文体**（如《菜根谭》《蒙田随笔》）往往没有这条线。

填不出来时**不要硬编**，照实写：

```
> **论证路径**：本章为格言体，无线性论证；核心由 N 组「格言 + 作者自注」构成
```

**关键在"照实"二字。** 硬凑一个"主张→依据→结论"，就是《精读指令》第八条禁止的**内部脑补**。

## 二、简版（快速精读）

### 文件头
```markdown
# 《书名》精读（作者·朝代/年代）

> **来源**：来源说明 | **类型**：类型 | **置信度**：高/中/低 | **精读日期**：YYYY-MM-DD

> **目标读者与阅读价值**：一句话说清这书适合谁读、读它能拿到什么
```

### 正文结构
```markdown
## 一书概况
- **作者**：...
- **书名**：来源与寓意
- **结构**：全书框架

## 一、主题板块一（如 入世智慧）
### 子板块（如 修身篇）
**金句原文** + 粗体解读
- 要点补充

## 二、主题板块二
...

## 三、总结升华
（1-2 段提炼 + 现代意义）

## 金句摘录
- "..."

## 存疑清单
（页码/位置不清的 · 认不准的字词 · 术语概念不确定的）

## 覆盖度报告
（原书总条目数 · 详述了哪些 · 略过了哪些及原因）

## 可关联主题
（5-10 个关键词）

## 关联
🔗 **强制 ≥5 条**交叉链接
```

### 简版要点
- 每节 = 金句原文 + 一句粗体解读（不展开长文）
- 主题分块按原书自然结构（入世/出世、修身/处世/心性等）
- 总结升华要有实际用处

## 三、精读完成后必做

1. **登记索引**：在索引文件里加一行（编号续接 / 文件路径 / 内容摘要 / 重要度 / 置信度 / 日期 / 保质期 / 关联条目）
2. **同步备份**：源目录与备份目录都要更新
3. **来源标注**：视频精读 vs 原著精读必须区分，标置信度，二手内容先与原著核对
